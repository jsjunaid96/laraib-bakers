Laraib Bakers & Sweets — VS Code project

Files:
- index.html  (open this)
- style.css   (all styling)
- script.js   (menu filter, cart, checkout logic)

How to run:
1. Open this folder in VS Code
2. Open index.html and click 'Go Live' (Live Server extension), or just double-click index.html

Notes:
- Cart uses browser localStorage — no database needed for this trial.
- Checkout opens a pre-filled WhatsApp order (0324-1111663).
- Menu prices marked demo are trial prices; 4 items carry the bakery's real published prices.
- To change anything later, ask Muse and a fresh copy of this project will be sent.
